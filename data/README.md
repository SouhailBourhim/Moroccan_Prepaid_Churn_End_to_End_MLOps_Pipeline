# Data Directory

Raw data is **not committed to git** — it is tracked via DVC.

## Layout

```
data/
  raw/
    expresso/          ← PRIMARY training dataset (Zindi)
      Train.csv
      Test.csv
      VariableDefinitions.csv
    cell2cell/         ← REFERENCE dataset (cross-dataset validation only)
      cell2celltrain.csv
      cell2cellholdout.csv
    orange/            ← REFERENCE dataset (cross-dataset validation only)
      churn-bigml-80.csv
      churn-bigml-20.csv
  processed/           ← Intermediate outputs (generated by pipeline)
  features/            ← Final model-ready arrays (generated by pipeline)
  interim/             ← Scratch files (not tracked)
```

## Dataset Roles

| Dataset | Role | Used for training? |
|---------|------|--------------------|
| `expresso/` | Primary | Yes — all model training and evaluation |
| `cell2cell/` | Reference | No — EDA only, cross-dataset feature validation |
| `orange/` | Reference | No — EDA only, cross-dataset feature validation |

The reference datasets establish which feature *concepts* predict churn across different operators and geographies. Features with signal in all three are treated as robust. See `notebooks/04_cross_dataset_analysis.ipynb` for the full analysis.

| Column | Type | Missing | Description |
|--------|------|---------|-------------|
| `user_id` | string | 0% | Subscriber identifier (hashed) |
| `REGION` | category | 39.4% | Geographic region (14 unique) |

| `MONTANT` | float32 | 35.1% | Total recharge amount (XOF) |
| `FREQUENCE_RECH` | float32 | 35.1% | Number of recharges |

| `ARPU_SEGMENT` | float32 | 33.7% | Average revenue per user (monthly) |
| `FREQUENCE` | float32 | 33.7% | Number of transactions |
| `DATA_VOLUME` | float32 | 49.2% | Data usage (MB); missing = never used data |
| `ON_NET` | float32 | 36.5% | Calls to same-operator subscribers |
| `ORANGE` | float32 | 41.6% | Calls to Orange subscribers |
| `TIGO` | float32 | 59.9% | Calls to Tigo subscribers |
| `ZONE1` | float32 | 92.1% | Calls to Zone 1 (international) |
| `ZONE2` | float32 | 93.6% | Calls to Zone 2 (international) |
| `MRG` | category | 0% | VAS subscription flag (YES / NO) |
| `REGULARITY` | float32 | 0% | Active days in 90-day window [0, 90] — **strongest predictor** |
| `TOP_PACK` | category | 41.9% | Most-used data/call bundle (140 unique) |
| `FREQ_TOP_PACK` | float32 | 41.9% | Usage frequency of TOP_PACK |
| `CHURN` | int8 | 0% | Target: 1 = churned, 0 = retained |

### Missingness notes

High missingness in usage columns is **informative (MNAR)**: a missing value means the subscriber never used that service. Churn rate is 2–4× higher among subscribers with missing usage columns. The pipeline adds `{col}_missing` indicator flags before imputing 0 into usage columns.

`REVENUE ≈ ARPU_SEGMENT × 3` — near-perfect linear relationship (Spearman ρ = 1.00). `ARPU_SEGMENT` is dropped from the model feature set to avoid multicollinearity.
